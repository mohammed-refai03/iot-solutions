Frequently Asked Questions

Everything you need to know about deploying and scaling enterprise IoT Solutions.

How long does a typical enterprise IoT gateway & sensor deployment take?
Most initial site surveys and zero-touch gateway deployments are completed within 48 to 72 hours. Our pre-flashed TPM 2.0 gateways connect instantly via LoRaWAN, Cellular, or Wi-Fi mesh without interrupting existing operations.
Is my telemetry data encrypted and protected against cyber threats?
Yes. All sensor payloads are encrypted at the hardware level using TLS 1.3 and SOC 2 Type II compliant zero-trust protocols. Gateway credentials are flashed directly onto hardware Root-of-Trust chips to prevent spoofing.
What wireless communication protocols do your IoT sensors support?
We support multi-protocol routing across LoRaWAN for long-range facility telemetry, NB-IoT / LTE-M for cellular failover, Wi-Fi 6 for high-throughput edge video analytics, and BLE 5.2 for localized asset tracking.
Can Stackly IoT integrate with our existing ERP or SCADA systems?
Absolutely. Our unified cloud telemetry pipeline provides real-time Kafka / MQTT streams and REST API Webhooks that route directly into SAP, Oracle SCADA, AWS IoT Core, Microsoft Azure, and custom enterprise portals.
What happens if our primary Internet connection goes down?
Edge gateways continue localized decision-making with sub-millisecond response times. Telemetry data is buffered securely on local gateway NVRAM and automatically syncs to the cloud as soon as cellular LPWAN failover reconnects.
Do you offer 24/7 proactive NOC monitoring and SLA guarantees?
Yes, all enterprise contracts include 24/7 proactive NOC monitoring with a guaranteed 99.999% gateway availability SLA. Automated AI health engines detect network anomalies and dispatch remote updates before failures occur.
