Frequently Asked Questions

Answers to common inquiries about our enterprise IoT hardware, gateways, and field deployments.

How long does a typical enterprise IoT deployment take?
Deployment timelines vary based on project scale. Initial site surveys and zero-touch gateway deployments are completed within 48 to 72 hours, while enterprise-wide industrial IoT integration across multiple facilities takes 2 to 4 weeks.
Do I need existing wired infrastructure for sensor deployments?
No. While hardwired Ethernet is supported, our gateways operate on multi-protocol wireless networks including LoRaWAN for long-range telemetry, Wi-Fi 6 for high-speed edge analytics, and dual-SIM Cellular LTE-M for instant connectivity.
Is our sensor data and telemetry payload encrypted?
Yes. All sensor payloads are encrypted at the hardware level using TLS 1.3 and SOC 2 Type II compliant zero-trust protocols. Gateway credentials are flashed directly onto hardware Root-of-Trust chips to prevent unauthorized access.
What happens if our primary Internet connection goes down?
Edge gateways continue localized decision-making with sub-millisecond response times. Telemetry packets are buffered securely on local gateway NVRAM and automatically sync to the cloud as soon as cellular LPWAN failover reconnects.
How does zero-touch hardware provisioning work for new site deployments?
Gateways are pre-configured with TPM 2.0 cryptographic certificates prior to shipping. Once powered on and connected to any network (Cellular, LoRaWAN, or Ethernet), the gateway automatically authenticates with our cloud NOC and downloads its assigned sensor telemetry configuration within seconds.
Can Stackly IoT integrate with our existing ERP or SCADA software?
Absolutely. Our unified cloud telemetry pipeline provides real-time Kafka / MQTT streams and REST API Webhooks that route directly into SAP, Oracle SCADA, AWS IoT Core, Microsoft Azure, and custom enterprise portals.
What NOC support SLA guarantees are included with enterprise plans?
All enterprise contracts include a guaranteed 99.999% telemetry router availability SLA, 24/7/365 NOC emergency hotline access, sub-15-minute emergency ticket response times, and automated OTA firmware health monitoring.
